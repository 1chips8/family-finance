## 当前扩展范围

- 月度总预算与分类预算：家长维护，展示支出、剩余、使用率和超支情况。
- CSV：按权限和筛选导出；导入预览、逐行错误、提交时重新校验与事务写入。
- 周期流水：模板维护、手动按月生成到期记录、模板与月份去重。不是定时自动扣款或银行交易。
- 统计增强：与紧邻等长上期比较的环比、储蓄率、支出异常与家庭月报。尚无独立去年同期同比和“复制上一笔”入口，可作为后续扩展，不列为已实现。
- 操作日志：家长查看家庭业务变更记录。
- 前端：风格 C 的蓝色、朱红与纸白；路由及组件按需加载；本地日期、记账入口查询参数与字段提示改进。
- 登录页：新增本地纸感账本与住宅插画背景，保持原配色，仅隐藏登录页左上角商标。

数据库共八张业务表。V1 建立 `household`、`app_user`、`finance_category`、`ledger_entry`；V2 增加 `monthly_budget`、`recurring_template`、`recurring_generation`、`audit_log`。Flyway 元数据表不计入业务表数量。

## 验证证据与边界

已记录证据：后端 `clean verify` 的 18 个测试通过；隔离 MySQL 8.4 的 V1/V2 迁移通过；前端 25 个测试、类型检查和生产构建通过。CSV 调整后已有前端门禁，登录视觉变更后又通过生产构建。本次为文档同步，未重复运行上述后端全量测试。

API 冒烟覆盖认证、家庭和业务查询、部分新增与清理、预算保存删除、周期模板创建删除、CSV 导出预览导入、普通成员导出隔离及预算/审计越权拒绝。不能据此宣称所有 CRUD、并发及浏览器组合完整通过。

CSV 浏览器侧此前只观察到“已开始下载”提示，缺少下载文件落盘及内容核对的独立留证，仍应纳入验收。详细记录见 [测试验收材料](../docs/stages/05-测试验收与报告素材.md)。
