# 阶段五：测试、验收与报告素材

## 1. 阶段目标

在不扩展功能的前提下收敛缺陷，记录系统由当前源码可构建、可启动、权限正确、增强功能可定向验收的证据，并生成课程报告需要的真实素材。

## 2. 依赖与输出

**进入条件**：阶段四统计正确、全部页面可用且无已知阻断问题。

**输出**：

- 后端和前端门禁结果及其对应源码版本。
- 从当前源码启动后的核心与增强功能演示验收记录。
- README 最终运行说明和演示账号。
- 架构图、ER 图、页面截图、测试摘要和报告章节素材清单。
- 明确的遗留问题记录；不在本阶段临时添加新功能。

## 3. 收敛顺序

1. 冻结需求，以 PRD 验收项建立检查表。
2. 运行后端相关测试，修复权限、数据一致性和业务规则问题；覆盖 V1/V2 迁移、预算、周期、CSV、统计和审计。
3. 运行前端类型检查与单元测试，修复路由、表单、日期、CSV 入口和错误状态问题。
4. 执行最终生产构建，检查实际变更、配置秘密和生成物；若源码随后再变更，旧门禁只作为历史证据。
5. 从当前源码启动两端，按演示脚本完成核心与增强功能的浏览器验收，并单独记录尚无文件落盘证据的 CSV 下载结果。
6. 在验收通过的界面上统一截图并整理报告素材。

## 4. 最终自动化门禁

```powershell
cd backend

cd ..\frontend

```

通过标准：所有命令退出码为 0；测试不是因跳过、过滤错误或未发现测试而“伪通过”。若 Testcontainers 受本机环境阻塞，必须说明原因并使用专用 MySQL 测试库重新执行同等集成用例。

## 5. 完整演示脚本

1. 启动 MySQL、后端和前端，打开系统并确认无需公网资源。
2. 注册账号 A，创建家庭并记录邀请码；确认 A 为家长。
3. 注册账号 B，用邀请码加入；确认 B 为普通成员。
4. A 新建收入和支出分类，分别为 A、B 记录多笔跨月流水。
5. B 登录，确认只看到和维护本人明细，但能看到家庭聚合统计。
6. B 尝试成员管理、分类管理、他人流水和预算编辑接口，确认被拒绝。
7. A 修改成员编号/姓名，停用并恢复一个分类；确认历史数据保留。
8. A 删除一条流水，确认列表和统计同步排除。
9. A 设置/删除家庭总预算和分类预算；B 只读执行状态，不能编辑。
10. A 创建并删除周期模板；在可用月份触发生成，观察已生成/跳过/重复生成提示。
11. 导出当前筛选结果，修改 CSV 后先预览再提交导入；确认错误行不写入，并记录浏览器是否实际产生下载文件。
12. 查看环比、储蓄率、预算执行、异常支出和家长专属操作日志。
13. A 尝试停用或降级最后一名家长，确认操作失败且数据不变。
14. 刷新、退出、重新登录，并在手机宽度完成一次新增收支。

演示中每一步记录“账号、操作、预期、实际结果、证据范围”，失败时先修复根因，再从受影响步骤重验；定向 smoke 不写成完整 CRUD 或全项目无缺陷。

- **记录但不扩展**：通知、附件、更多图表、动画和生产部署设想；预算、周期、CSV、统计增强和审计属于当前版本，按证据范围验收。

## 10. 停止条件与最终证据

只有以下条件同时满足才可声明课设系统完成：

1. 最终自动化门禁对当前源码全部通过。
2. 完整演示脚本通过，关键失败路径与权限边界得到验证。
3. 实际 diff 无秘密、调试残留、无关生成物或越界功能。
4. README 能让同一台本机按说明重新启动。
5. 报告素材来自最终系统，且计划、源码、截图和文字一致。

若任一项未满足，应明确写为“未完成/受阻”，记录已完成验证和剩余风险，不用页面可打开或部分测试成功代替最终结论。
