## 正式提交前

1. 替换姓名、学号、专业班级和指导教师占位符，按学校要求核对封面日期。
2. 对照实际参与、修改、测试记录核实个人贡献，不将责任划分直接当作已完成的个人工作。
3. 向教师说明成员删除采用停用保留历史账目，以及 Java 17 / Spring Boot 的 Java Web B/S 技术路线。
4. 验收时核对 CSV 实际保存文件及内容，不以页面“开始下载”提示作为最终依据。
