## 权威关系

- 课程硬性要求以 `资料/软件项目设计任务书-6-家庭理财系统的设计与实现.docx` 为准。
- 报告章节与格式以 `资料/软件项目设计报告2026年.docx` 为准。
- 产品行为以 PRD 为准；技术实现以架构设计为准；实施顺序以总计划和阶段文档为准。
- 若需求发生变化，先更新 PRD，再同步架构与受影响的阶段文档，避免文档与源码口径分裂。

## 课设边界

- 目标是完成一个可本机演示、可解释、可写入课程报告的最小完整系统。
- 不按生产金融系统建设，不引入微服务、消息队列、云服务、支付接口、银行同步、高可用或复杂运维。
- 用户确认的增强版已包含预算、周期流水、CSV 导入导出、增强统计和操作日志；仍不包含提醒、票据附件、多家庭、公网部署和视频介绍。
- 当前已形成课程小组责任分配建议；个人报告中的实际贡献仍应以真实接手、修改、测试和答辩记录为准。
