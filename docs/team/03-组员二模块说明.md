# 组员二前端模块说明

## 1. 责任目标

组员二负责把后端能力组织成完整、清晰、可响应式演示的 Vue 应用。工作范围包括应用骨架、路由和会话状态、业务页面、图表、表单、错误状态、桌面/手机适配以及前端自动化测试。

## 3. 实现逻辑

### 3.1 应用启动与路由守卫

应用启动后先由 auth store 调用 `/api/auth/me` 恢复会话。路由守卫根据 `requiresAuth`、用户是否入户和当前角色决定去向：未登录进入登录页，已登录未入户进入 `/onboarding`，已入户进入业务页面。401 清理认证状态并跳转登录；真实 403 触发专用事件并进入 `/forbidden`；未知地址进入 404。

### 3.2 API 与 CSRF

Axios 使用 `/api` 统一前缀，Vite 开发代理转发到 Spring Boot。修改请求前确保已获取 CSRF Token，浏览器自动携带 Session Cookie；响应拦截器把后端 `{ code, message, fieldErrors }` 转换为页面可读错误。页面只传业务筛选条件，不传可信家庭 ID。

### 3.3 登录、注册与入户动线

登录/注册表单完成本地必填和格式校验后调用 auth store；成功后根据是否已有家庭跳转。入户页提供“创建家庭”和“使用邀请码加入”两个分支，成功后重新获取当前用户并进入仪表盘。登录页可识别修改密码后的查询参数，提示使用新密码。

### 3.4 仪表盘

`DashboardView.vue` 维护本月、近 3 个月、今年和自定义时间范围，把起止日期传给统计接口。接口结果映射到三张 KPI、12 月趋势、收入/支出构成、成员收入/支出/结余和最近流水。图表在无数据时显示明确空状态；负结余使用支出语义颜色。

### 3.5 收支、成员与分类页面

收支页维护日期、类型、分类、成员和分页条件，家长能选择家庭成员，普通成员不显示越权选项。新增/编辑复用 `EntryForm.vue`，类型变化时重新筛选分类。桌面使用表格和抽屉，390px 手机宽度隐藏桌面表格并显示卡片列表与全屏表单。

成员页显示家庭通行证、家庭名称和角色；邀请码、复制和重置只对家长显示。分类页按收入/支出组织系统分类和家庭分类，普通成员只读；危险操作使用确认框。

### 3.6 状态、可访问性与视觉

统一提供骨架、空数据、原位错误、重试、403 和 404。颜色、圆角、阴影和间距由 token 统一；金额同时使用文字、正负号和颜色表达，不能只依赖颜色。响应式断点保证导航、时间控件、邀请码和成员金额不产生横向滚动，并支持 `prefers-reduced-motion`。
