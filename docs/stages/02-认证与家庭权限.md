# 阶段二：认证与家庭权限

## 1. 阶段目标

完成系统信任边界：账号注册登录、服务端会话、CSRF、创建/加入家庭、家长与普通成员角色以及家庭数据隔离。该阶段正确性优先于页面美化。

## 2. 依赖与输出

**进入条件**：阶段一数据库迁移和两端基础构建通过。

**输出**：

- 注册、登录、退出、当前会话和 CSRF 接口。
- 创建家庭、邀请码加入、当前家庭和重置邀请码接口。
- Spring Security 访问规则、当前用户上下文和统一 401/403 处理。
- 登录、注册、入户页面及前端会话恢复/路由守卫。
- 覆盖身份、CSRF、角色和跨家庭隔离的后端集成测试。

## 3. 范围边界

本阶段只实现身份和家庭归属，不实现成员编辑、分类管理、收支 CRUD 或统计。登录/注册页先达到完整可用和基础视觉一致，最终细节在阶段四统一。

## 4. 后端模块责任

| 模块 | 责任 |
|---|---|
| `auth` | 注册校验、BCrypt、登录/退出、`/me`、停用账号拒绝 |
| `household` | 创建家庭、邀请码生成/校验/轮换、首次成员编号、角色赋值 |
| `common/security` | SecurityFilterChain、CSRF、401/403 JSON、当前用户上下文 |
| `common/error` | 400/401/403/404/409 稳定错误码和字段错误 |

安全规则：除认证、健康检查和入户接口外，业务接口要求已认证且已入户；所有写请求要求有效 CSRF。`householdId` 和角色只从会话中的当前用户重新读取，不信任请求参数。

## 5. 前端模块责任

| 位置 | 责任 |
|---|---|
| `src/api/auth.ts`、`households.ts` | 认证与入户接口封装 |
| `src/stores/auth.ts` | 当前用户、家庭状态、会话恢复、退出 |
| `src/router/` | 未登录、未入户和已入户三种状态的路由重定向 |
| `views/LoginView.vue` | 用户名/密码、错误保留、登录提交 |
| `views/RegisterView.vue` | 用户名/姓名/密码确认和字段错误 |
| `views/OnboardingView.vue` | 创建家庭与邀请码加入两个明确入口 |

## 6. 实施任务

1. 建立注册 DTO 与服务：验证用户名、姓名和密码规则，检查用户名冲突，BCrypt 后创建未入户账号。
2. 配置基于 Session 的认证，成功和失败均返回统一 JSON；退出销毁会话。
3. 提供 CSRF 初始化端点，前端 Axios 在写请求中发送 Token，并携带 Cookie。
4. 实现 `/api/auth/me`，返回前端路由所需的最小身份：用户 ID、姓名、角色、状态、是否入户和家庭摘要。
5. 实现创建家庭事务：确认用户未入户 → 生成唯一邀请码 → 创建家庭 → 用户成为 `M001/PARENT`。
6. 实现邀请码加入事务：确认用户未入户和邀请码有效 → 生成家庭内下一个成员编号 → 用户成为 `MEMBER`。
7. 实现家长重置邀请码，旧邀请码立即失效；普通成员调用返回 403。
8. 建立当前用户上下文，后续服务统一从这里获取 `userId/householdId/role`。
9. 完成三个前端页面、会话恢复、路由守卫和 401/403 处理。
10. 增加 `demo` 账号初始化：一个家长、一个成员、一个未入户账号；密码仅写在 README 的演示说明中，不用于生产配置。

## 7. 必测场景

| 场景 | 预期 |
|---|---|
| 重复用户名注册 | 409，稳定错误码，数据库不新增用户 |
| 无 CSRF 的写请求 | 被拒绝，数据不变化 |
| 未登录访问业务接口 | 401 JSON，不返回 HTML 登录页 |
| 未入户访问仪表盘接口 | 403 或约定业务错误，前端跳转入户 |
| 创建家庭后再次创建/加入 | 冲突并保持原家庭不变 |
| 错误或旧邀请码 | 404/409 的明确提示，不加入家庭 |
| 普通成员重置邀请码 | 403 |
| 停用账号登录 | 拒绝登录 |
| 伪造其他 `householdId` | 服务端忽略或拒绝，不泄露数据 |

## 8. 验收流程

1. 注册账号 A，创建“演示家庭”，确认 A 为 `M001/PARENT`。
2. 注册账号 B，用邀请码加入，确认 B 为 `M002/MEMBER`。
3. B 尝试重置邀请码，确认前后端均不允许。
4. A 重置邀请码，注册账号 C 用旧码加入失败、用新码成功。
5. 退出并刷新页面，确认会话与路由状态正确恢复或跳转。

## 9. 停止条件与阶段证据

认证、CSRF、入户事务、角色判定和跨家庭测试全部通过，三类用户能进入正确页面即停止。保存集成测试结果和 A/B/C 演示记录；前端视觉不在本阶段反复打磨。
