# 家庭理财系统实施总计划

## 1. 文档用途

本文把已确认的 PRD 和架构拆成可执行阶段，并记录当前验收版本的总体门禁。核心阶段与月报增强范围均已有源码实现。

## 2. 项目定位与完成目标

- **项目模式**：Java Web 软件课程设计，而非生产金融系统。
- **实施目标**：在本机完成一个可运行、可演示、可测试、可写入课程报告的最小完整系统。
- **核心闭环**：注册登录 → 创建/加入家庭 → 权限区分 → 成员与分类管理 → 收支 CRUD → 家庭统计 → 测试与报告取材。
- **完成定义**：任务书要求有对应功能，家长与普通成员的关键权限可被验证，前后端均能从当前源码构建并完成演示流程。

用户后续确认实施预算、周期流水、CSV 导入导出、增强统计和操作日志；仍不实施消息、附件、多家庭、第三方支付、微服务、Redis、消息队列、公网部署和生产级运维。

## 3. 阶段依赖

```mermaid
flowchart LR
    S1[阶段一\n项目骨架与数据库] --> S2[阶段二\n认证与家庭权限]
    S2 --> S3[阶段三\n成员、分类与收支]
    S3 --> S4[阶段四\n统计与前端视觉]
    S4 --> S5[阶段五\n测试、验收与报告素材]
```

阶段原则：一个阶段达到停止条件后再进入下一阶段；发现接口或数据模型问题时，回到对应权威文档修改，禁止只在代码中悄悄改变方案。

## 4. 3—5 天建议进度

这是个人完成课设的紧凑安排，可按实际课程时间拉长，但不改变阶段顺序。

| 时间 | 主要工作 | 当日里程碑 |
|---|---|---|
| 第 1 天 | 阶段一；开始阶段二 | 数据库可迁移，前后端骨架可启动，注册登录链路初步可用 |
| 第 2 天 | 完成阶段二；开始阶段三 | 创建/加入家庭与权限隔离可验证，成员和分类基本完成 |
| 第 3 天 | 完成阶段三；开始阶段四 | 收支 CRUD 闭环完成，仪表盘统计接口完成 |
| 第 4 天 | 完成阶段四；执行阶段五 | 全部页面和响应式视觉完成，自动测试及演示流程通过 |
| 第 5 天（缓冲） | 修复问题、截图、整理报告素材 | 当前源码最终门禁通过，报告证据齐全 |

如果只有 3 天，压缩页面装饰和非核心前端单元测试，不删除权限隔离、数据校验、核心后端测试或最终构建。

## 6. 实施顺序与变更规则

1. 先实现数据库和后端业务约束，再接前端页面，避免用界面逻辑代替鉴权。
2. 每个业务模块先完成成功路径，再覆盖无权限、冲突和非法输入。
3. 前端先保证信息结构和操作闭环，再统一视觉；不在核心功能未通时制作重动效。
4. 发现必须新增依赖、业务表或第一版功能时，先判断任务书是否真的需要；不需要则记为后续设想，不实施。
5. 后续真实多人协作时再按实际承担模块记录贡献；当前文档不虚构 40%/30%/30% 分工。

## 7. 测试策略

| 层级 | 重点 | 方式 |
|---|---|---|
| 后端单元/集成 | 注册冲突、CSRF、角色、家庭隔离、最后家长、分类约束、流水校验、统计精度 | JUnit、Spring Security Test、MySQL Testcontainers |
| 前端单元 | 会话恢复、路由守卫、角色操作显隐、表单联动、401/403 处理 | Vitest、Vue Test Utils |
| 接口联调 | Cookie 会话、CSRF、统一响应、筛选分页 | 从当前前后端源码启动后操作 |
| 课程验收 | 家长和成员两套账号完成规定演示动线 | 浏览器手工验收并保留截图 |

后续若本机无法运行 Testcontainers，可使用专用测试库替代，但必须记录环境原因，且不能跳过权限与隔离测试。

## 8. 最终权威门禁

在所有代码、依赖和配置收敛后，只对当前源码执行一次完整门禁：

```powershell
cd backend
.\mvnw.cmd clean verify

cd ..\frontend
npm run type-check
npm run test:unit
npm run build
```

随后从当前源码启动 Spring Boot 和 Vite，执行阶段五的完整浏览器演示流程。页面能打开、旧进程可访问或单个接口成功都不能替代上述构建和启动验证。

## 9. 最终交付物

- `backend/`：Spring Boot 源码、迁移、测试、Maven Wrapper 和示例配置。
- `frontend/`：Vue 源码、测试、lockfile 和生产构建配置。
- 根目录 `README.md`：环境要求、MySQL 配置、启动命令、演示账号、演示流程和常见问题。
- `docs/`：PRD、架构、实施总计划及阶段记录。
- 课程报告素材：功能截图、架构图、ER 图、测试结果摘要和本人实际完成内容。
