# 阶段四：统计与前端视觉

## 1. 阶段目标

完成基础与增强统计和统一前端体验，使系统达到课程展示质量。视觉服务于信息表达，不引入与课设无关的视频、重动画或营销内容。

## 2. 依赖与输出

**进入条件**：阶段三业务 CRUD、权限和校验测试通过，并已有可用于统计的流水数据。

**输出**：

- 仪表盘聚合接口和统计 SQL。
- KPI、12 月趋势、收支构成、成员对比和最近流水。
- Style C“家庭月报”应用壳、Bento Grid 信息布局和统一 Token。
- 业务页面及认证/状态页的最终布局、响应式、加载/空/错误/无权限状态。
- 图表数据精度和关键前端状态测试。

## 3. 统计契约

`GET /api/statistics/dashboard?from=&to=` 一次返回仪表盘需要的数据：

- 选定范围总收入、总支出、结余。
- 截止月份向前 12 个月的收入/支出趋势，无数据月份补零。
- 收入和支出类别构成。
- 当前家庭各成员收入、支出和结余对比。
- 最近若干条调用者有权查看的流水。
- 上期等长范围环比、储蓄率、预算执行和满足基线条件的支出异常提示。

普通成员可获得家庭聚合统计和成员汇总，但最近流水只能包含本人明细。统计使用数据库聚合和 `BigDecimal`，排除逻辑删除流水，不维护冗余汇总表。

## 4. 视觉方案

| 区域 | 设计来源与落地 |
|---|---|
| 登录/注册 | 登录页使用仓库内 `frontend/public/images/login-ledger-paper-v1.png` 的蓝纸账本背景；`/login` 隐藏左上品牌标记，其他认证页保留品牌；不使用视频、外链字体或外部素材 |
| 登录后外壳 | Style C 纸张报告：米白页面、墨色顶栏、群青/朱红重点和竹青收入状态；保留清晰分隔和克制圆角 |
| 仪表盘 | 以月份竖栏、结余主数字、编辑式 KPI、趋势/构成、预算、成员、异常和最近流水组成家庭月报；不照搬参考项目代码 |
| 业务页 | 沿用同一外壳，桌面表格/抽屉，移动卡片/全屏表单 |

统一 Token：群青/品牌蓝 `#174b9c`、墨色 `#171614`、米白页面 `#f4f0e8`、竹青收入 `#277a65`、朱红重点 `#b8402f`；当前外壳/卡片/控件采用 0/4/3px 的克制圆角；动效 180—220ms，并尊重 `prefers-reduced-motion`。

## 5. 页面实施任务

1. 建立 `AppLayout`：品牌、胶囊导航、欢迎信息、头像菜单、退出和“记一笔”主按钮。
2. 仪表盘按线框实现三张 KPI、趋势图、收支构成、成员对比和最近流水；卡片高度和视觉权重随信息重要性设置。
3. 为 ECharts 建立轻量图表封装，只统一空数据、Resize 和主题色，不创建通用图表框架。
4. 完成收支、成员、分类和资料页面的最终排版，复用 Element Plus 的表单、表格、分页、抽屉和弹窗能力。
5. 为全部数据页补齐骨架屏、空状态、字段错误、接口错误、重试、403 和 404。
6. 在窄屏下将顶部导航收纳、表格切换卡片、编辑抽屉切换全屏；保证主要按钮和金额信息无需横向滚动。
7. 检查键盘焦点、表单标签、颜色对比、图标可理解性和危险操作文案。
8. 清理临时占位、调试数据和外部资源依赖，所有演示数据来自后端 `demo` Profile。

## 6. 统计正确性测试

使用一组可人工核算的数据：至少两名成员、收入/支出各两个分类、跨两个月、包含一条逻辑删除流水和一个停用分类。

| 验收项 | 通过标准 |
|---|---|
| KPI | 收入、支出、结余与人工求和完全一致 |
| 12 月趋势 | 固定 12 个连续月份，空月份为 0，顺序正确 |
| 类别构成 | 分组总额之和等于对应收入/支出总额 |
| 成员对比 | 每个成员汇总正确，停用成员历史仍参与 |
| 删除过滤 | 逻辑删除记录不进入任何汇总 |
| 权限 | 普通成员看得到家庭汇总，但最近流水无他人明细 |

## 7. 前端测试与视觉验收

- Vitest 覆盖会话恢复、路由守卫、角色操作显隐、类型—分类联动和 401/403 处理。
- 在桌面宽度约 1440px、平板约 768px、手机约 390px 检查核心页面。
- 网络延迟模拟下不出现重复提交、布局大幅跳动或空白页面。
- 图表为空时显示解释和操作入口，不显示报错或无意义坐标轴。
- 不要求像素级复刻参考图，要求布局、层级、圆角、色彩和交互语言统一。

## 8. 阶段验收流程

1. 使用家长账号进入仪表盘，核对 KPI、趋势、构成和成员对比。
2. “记一笔”新增流水后返回仪表盘，确认统计刷新。
3. 使用普通成员账号核对聚合统计和本人最近流水边界。
4. 依次访问收支、成员、分类、资料页，检查导航和角色操作显隐。
5. 在手机宽度完成一次新增收支和一次筛选。
6. 人为制造空数据、403 和接口失败，确认状态页/原位错误可理解且可恢复。

## 9. 停止条件与阶段证据

统计数据与人工核算一致，业务页面及认证/状态页具备统一视觉和完整状态，桌面与手机核心操作可用，前端定向测试通过即停止。不继续制作视频介绍、营销首页或额外动画。保留最终截图候选和核算数据，进入阶段五。
