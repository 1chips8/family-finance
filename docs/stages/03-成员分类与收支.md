# 阶段三：成员、分类与收支

## 1. 阶段目标

完成任务书要求的主要业务 CRUD，并把权限规则落实到后端查询和修改边界。阶段结束时，家庭可以真实录入并维护收支数据。

## 2. 依赖与输出

**进入条件**：阶段二身份、家庭归属和角色测试通过。

**输出**：

- 成员列表、资料/编号/角色修改、停用与恢复。
- 系统分类读取和家庭自定义分类新增、改名、停用与恢复。
- 收支新增、分页筛选、修改和逻辑删除。
- 成员、分类、收支三个前端业务页面及表单。
- 业务校验、越权和逻辑删除测试。

## 3. 业务边界

- 普通成员可看家庭成员名单，但不能编辑成员。
- 普通成员只查询和维护本人流水；家长可处理本家庭所有流水。
- 系统分类不可编辑；家庭自定义分类只有家长可管理。
- 成员和分类用状态停用，流水用逻辑删除；不物理删除历史数据。

## 4. 模块与页面责任

| 模块/页面 | 责任 |
|---|---|
| 后端 `household/member` | 当前家庭成员查询、编号/姓名/角色/状态规则 |
| 后端 `category` | 系统与家庭分类合并查询、自定义分类管理 |
| 后端 `ledger` | 权限范围内的流水 CRUD、分页和筛选 |
| `MembersView.vue` | 成员列表、家长行操作、危险操作确认 |
| `CategoriesView.vue` | 收入/支出页签、系统/自定义标记、状态管理 |
| `EntriesView.vue` | 筛选、分页、表格/卡片、右侧抽屉表单 |
| 通用表单组件 | 类型—分类联动、金额、日期、备注和字段错误 |

## 5. 实施任务

### 5.1 成员管理

1. 查询当前家庭成员，返回编号、姓名、角色、状态和加入时间，不返回密码等敏感字段。
2. 家长可修改成员编号、姓名和角色；成员编号规范化后在家庭内唯一。
3. 家长可停用或恢复成员；停用后其现有会话在下一请求重新检查状态并失效。
4. 降级或停用家长前统计活跃家长数量，确保至少保留一名。
5. 普通成员的编辑/状态操作即使绕过前端直接调用也返回 403。

### 5.2 分类管理

1. 查询时合并启用的系统分类与当前家庭分类，管理页可额外查看已停用家庭分类。
2. 新增自定义分类时校验类型、名称及家庭内同类型重名。
3. 系统分类拒绝修改；自定义分类只能由当前家庭家长修改。
4. 分类已被历史流水引用时允许停用但不删除；停用分类不可用于新流水。

### 5.3 收支管理

1. 列表默认按发生日期、创建时间倒序，每页 20 条，最大 100 条。
2. 支持日期范围、类型、分类和成员筛选；普通成员传入其他成员筛选时仍只得到本人数据。
3. 新增/修改统一验证金额、日期、备注、成员归属、分类状态和类型匹配。
4. 普通成员的归属成员由服务端强制为本人；家长才可选择本家庭其他成员。
5. 修改与删除前同时检查流水未删除、属于当前家庭且操作者有权处理。
6. 删除只更新逻辑删除标记，所有列表和后续统计统一排除。

### 5.4 前端交互

1. `EntriesView` 桌面端为筛选栏、表格、分页和右侧抽屉；移动端改为卡片列表和全屏表单。
2. 类型改变时清空不匹配分类，只展示相同类型且可用的分类。
3. 家长表单显示成员选择；普通成员固定显示本人且不允许伪造。
4. 成员和分类页面对普通成员隐藏编辑入口，并保留只读说明。
5. 只有删除流水、停用成员和停用分类使用确认弹窗；普通保存不二次确认。

## 6. 业务测试矩阵

| 模块 | 正常路径 | 关键失败路径 |
|---|---|---|
| 成员 | 家长改编号/姓名/角色、停用/恢复 | 编号冲突、普通成员越权、最后家长被降级/停用 |
| 分类 | 家长新增、改名、停用/恢复 | 重名、系统分类被改、普通成员越权、停用分类用于新流水 |
| 收支 | 两角色新增/查询/修改/删除 | 金额非正、未来日期、类型不匹配、跨家庭 ID、成员改他人流水 |
| 分页筛选 | 日期/类型/类别/成员组合筛选 | 非法页码、过大页长、普通成员伪造成员筛选 |
| 历史保留 | 停用成员/分类后查历史 | 历史显示丢失、逻辑删除仍出现在列表 |

金额测试至少覆盖 `0.01`、两位小数、零、负数和超过字段范围；日期测试使用后端当前本地日期，不能只依赖浏览器限制。

## 7. 阶段验收流程

1. 家长创建收入/支出自定义分类，并为自己和普通成员各录入流水。
2. 普通成员登录，只看见本人流水，能够新增、修改和删除本人记录。
3. 普通成员尝试请求他人流水和成员/分类编辑接口，确认后端拒绝。
4. 家长停用一个已被使用的分类，确认历史记录仍显示但新增表单不可选择。
5. 家长停用普通成员，确认其不能继续登录且历史记录保留。
6. 尝试停用或降级最后一名家长，确认系统拒绝。

## 8. 停止条件与阶段证据

三个业务模块的成功与失败路径通过自动测试，浏览器能够完成“建分类—记账—筛选—修改—删除”的闭环即停止。记录接口测试结果和关键页面截图草稿；统计与最终视觉留给阶段四。
